## Teardown

After the numbered tests, the collection's final folder (`ZZ Cleanup`) undoes everything the API is
able to undo, in dependency order, using only the ids this run captured: its bookings, leave
applications, staff member, appointment slots and service. Accounts and business profiles have no
delete operation in the API at all, so `cleanup_test_data.sql` removes those, matched on the run's
own stamp. Nothing is truncated and no pre-existing row is touched.
